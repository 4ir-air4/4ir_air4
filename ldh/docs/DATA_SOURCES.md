### KOSIS (`ldh/datasets/raw/reference/kosis/`)

[KOSIS Open API](https://kosis.kr/openapi/index/index.jsp) 인증키가 필요하다. `.env`에 `KOSIS_API_KEY=키`로 넣는다.

| 파일 이름 | 내용 | 기간·단위 | 통계표·코드 |
|---|---|---|---|
| 국내항공료_지수 | 전국 국내항공료 소비자물가지수 (2020=100). **노선별 금액이 아닌 지수** | 1975-01~2026-10, 월별, 622행 | `101/DT_1J22112`, 항목 `T`, 분류 `T10`, `F02G03301` |
| 국내선_노선별_운항 / 국내선_노선별_여객 | 국내선 운항(편), 여객(명). 도착·출발과 항공사는 합계 기준 | 합계 2005-01~2026-09, **노선별은 2020-02부터**, 월별 | `381/DT_920005_B004`, 항목 `T001` / `T002`, 분류 `ALL`, `B01`, `C01` |
| 교통요금_지수 | 소비자물가 품목 지수(2020=100): 국내항공료, 국제항공료, 시외버스료, 여객선료, 택시료. 국내항공료 비교용 | 2015-01~2026-10, 월별, 710행 | `101/DT_1J22112`, 항목 `T`, 분류 `T10`, `F02G03301+E01G03302+E01G03202+F02G03303+E01G03203` |
| 국내선_노선별_항공사별_운항 / 국내선_노선별_항공사별_여객 | 위 표를 항공사별로 나눈 값. 도착·출발은 합계. 항공사 이름은 KOSIS가 최신 이름으로 준다(예: TWB 트리니티항공) | 2020-01~2026-09, 월별, 약 6,390행. 노선별 항공사 합은 노선 합계와 같다(2026-11-10 확인). 전체 합계 행은 나누지 않은 노선까지 포함해 항공사 합보다 크다 | 같은 표, 분류 `ALL`, `B01`, `ALL` |

```bash
python -m ldh.download.download_kosis fetch --org 101 --tbl DT_1J22112 --item T --obj T10 --obj F02G03301 --start 197501 --name 국내항공료_지수
```

```bash
python -m ldh.download.download_kosis fetch --org 101 --tbl DT_1J22112 --item T --obj T10 --obj "F02G03301+E01G03302+E01G03202+F02G03303+E01G03203" --start 201501 --name 교통요금_지수
```

같은 표의 시도별 국내항공료는 17개 시도 모두 전국 값과 같아(2026-11-10, 최근 12개월 확인) 받지 않았다.

지수 값은 2004년까지 1년에 0~4번만 바뀐다. 2005년부터 바뀌는 횟수가 늘고, 2015-01 이후에는 매달 바뀐다. 계절성 학습에는 이 구간 차이를 고려해 기간을 정한다.

유가, 환율, 물가 (`ldh/categories/korea_airfare`의 입력). 2000-01부터 받았다.

| 파일 이름 | 내용 | 통계표·코드 |
|---|---|---|
| 원달러_환율 | 원/달러 기간평균 (IMF) | `101/DT_2IFS011`, 항목 `T004`, 분류 `1005`, `B2` |
| 원유_수입물가_달러 | 원유 수입물가지수, 달러 기준. **달러/배럴 가격이 아닌 지수** | `301/DT_401Y017`, 항목 `13103134644999`, 분류 `13102134644ACC_CD.20112101AA`, `13102134644CRR_CTRT_CD.D` |
| 제트유_생산자물가 | 제트유 생산자물가지수 | `301/DT_404Y016`, 항목 `13103134764999`, 분류 `13102134764ACC_CD.30412301AA` |
| 국내항공여객_생산자물가 | 국내항공여객 생산자물가지수 | `301/DT_404Y016`, 항목 `13103134764999`, 분류 `13102134764ACC_CD.50131102AA` |
| 소비자물가_총지수 | 전국 소비자물가 총지수 | `101/DT_1J22003`, 항목 `T`, 분류 `T10` |

KOSIS 검색에서는 국제유가 가격 표를 찾지 못했고, 한국은행 환율 표(`301/DT_036Y*`)는 2014년에서 끝난다.

노선별 표는 항목만 바꿔 받는다.

```bash
python -m ldh.download.download_kosis fetch --org 381 --tbl DT_920005_B004 --item T002 --obj ALL --obj B01 --obj C01 --start 200501 --name 국내선_노선별_여객
```

항공사별은 한 번에 4만 칸을 넘어 1년씩 나눠 받는다(운항은 `T001`, 이름 `국내선_노선별_항공사별_운항`).

```bash
python -m ldh.download.download_kosis fetch --org 381 --tbl DT_920005_B004 --item T002 --obj ALL --obj B01 --obj ALL --start 202001 --years-per-call 1 --name 국내선_노선별_항공사별_여객
```

노선별 표를 쓸 때 주의할 점:

- **합계 행:** `C1_NM == "합계"` 행과 노선 행을 함께 더하면 두 배가 된다. 분류 코드 `A01`이 합계다.
- **행이 없는 달:** 노선 행은 2020-02부터 있고, 운항이 없는 달은 0이 아니라 행 자체가 없다.
- **합계와의 차이:** 노선 합은 합계와 1% 이내로 맞지만 2020-03만 운항 8.6%, 여객 5.6% 차이 난다.
- **같은 공항 노선:** `김포-김포`처럼 출발과 도착 공항이 같은 노선 6개가 있다. 의미는 확인하지 못했다.
- **공식 수치 대조:** 2020~2025 연간 합계를 국토교통부 수송실적과 비교하면 운항은 2022년의 1편 차이를 빼고 같고, 여객은 약 1% 높다. 여객 차이의 원인은 확인하지 못했다.

## 2. 쓰기 전에 알아야 할 점

- **중복 집계:** 인천 운송실적은 상반기판(`_20230630`)과 연간판(`_20231231`)이 겹친다. 그대로 합치면 상반기가 두 번 집계된다.
- **인천 환승 파일의 결함:** 2024-01-01~05-15와 2024-07-01~11-05 자료가 없다. 2023년 6월은 상반기판과 하반기판에 모두 들어 있어 중복을 제거해야 한다. 2023 상반기 도착 파일은 컬럼명이 `출발국가, 출발공항`으로 잘못 표기되어 있다. 환승객 통계용 자료라 전체 운항편이 포함되는지는 확인하지 못했다.
- **기간을 알 수 없는 파일:** 지연·결항 현황에는 연도 컬럼이 없다. 파일명 날짜는 게시일이지 집계 기간이 아니다. 최신 지연 파일의 김포 국내선은 65,968편으로 직전 판의 107,426편보다 훨씬 적어, 연간치가 아닐 수 있다. 쓰기 전에 한국공항공사(02-2660-4803)에 기간을 확인한다.
- **버전 간 컬럼 차이:** 같은 데이터셋도 판마다 컬럼이 다르다. 예를 들어 인천 운송실적은 `년월`에서 `년도, 월`로 바뀌었고, 값도 `2025`와 `2026년`처럼 형식이 다르다.
- **인코딩:** 국내 CSV는 대부분 CP949이고 일부는 UTF-8이다. `pd.read_csv(path, encoding="cp949")`로 읽되 실패하면 `utf-8-sig`로 읽는다.
- **제도 변경:** 언론 보도에 따르면 국토교통부의 지연 기준은 활주로 기준(국내선 30분, 국제선 60분 초과)에서 게이트 기준 15분 이상으로 바뀌었다. 연도별 지연율을 비교할 때 변경 시점을 확인한다.
- **NTSB 형식:** 압축 안의 파일이 Access DB(`.mdb`)라서 별도 드라이버나 `mdbtools`가 필요하다.
- **EUROCONTROL 조건:** 출처를 표시해야 하고, 상업적 이용은 금지되며, 서면 허가 없는 수정도 금지된다. 가공이나 모델 학습이 "수정"에 해당하는지는 페이지에 명시되어 있지 않으니, 공개나 상업적 활용 전에 확인한다.
- **OpenSky 조건:** 원문은 `ldh/datasets/raw/reference/opensky_flightlist/LICENSE.txt`에 있다. 허용 목적은 비영리 연구, 비영리 교육, 상업적 내부 테스트·평가, 정부 목적이다. 같은 기관 소속 협업자에게만 공유할 수 있고, 다른 기관은 OpenSky에 직접 신청해야 한다. 조건을 팀원에게 알릴 책임은 데이터를 받은 사람에게 있고, 연구가 끝나면 사본을 삭제해야 한다. 공개물에는 항공기 식별자를 익명화하고 출처를 표기하며, 사본이나 링크를 OpenSky에 보내야 한다. 약관이 OpenSky의 모든 데이터셋에 적용된다고 되어 있어 `aircraftDatabase.csv`도 같은 조건으로 다룬다.
- **공개 저장소 금지:** 팀 저장소 `4ir-air4/4ir_air4`는 공개 상태이므로 `ldh/datasets/raw/reference/`를 올리지 않는다. 그 저장소의 `.gitignore`에 이 폴더를 추가해 두었다.
- **OpenSky 항공편 목록의 한계:** 출발·도착 공항은 ADS-B 궤적으로 계산한 값이고 외부 자료와 대조되지 않았으며, 찾지 못하면 비어 있다. 예정 시각이 없어 이 데이터만으로는 지연을 계산할 수 없다. 2021-05 파일은 05-30까지만 있다. 실제 컬럼에는 readme에 없는 첫·마지막 위치 값(`latitude_1` 등)도 있다.
- **기상 데이터는 예시 범위:** 14개 공항(ATL, DFW, DEN, ORD, LAX, CLT, MCO, LAS, PHX, MIA, RKSI, RKSS, RKPC, RKPK)의 2년치뿐이다. 시각은 UTC라서 현지 시각인 BTS와 조인할 때 변환이 필요하다. 범위는 `ldh/download/download_refs.py`의 `ASOS_STATIONS`와 기간 값으로 늘린다.
- **미수집 버전:** `국토교통부_연도별_항공사고_통계`의 2020-09-24판은 포털이 파일 대신 HTML을 돌려줘 받지 못했다. 최신판이 2002~2025년을 포함한다. 이 때문에 `ldh/download/download_refs.py`는 다시 실행해도 종료 코드 1로 끝난다.

## 4. 분석 목적별 추천 조합

| 목적 | 데이터 | 모델 예시 |
|---|---|---|
| 미국 항공편 지연 예측 | BTS + 기상(ASOS) + 공항 정보(OurAirports) | LightGBM, XGBoost |
| 인천공항 편별 지연 분석 | 인천 환승 파일의 계획·실제 시각 + RKSI 기상 | 분류, 회귀 |
| 국내 지연 수요·추세 예측 | 지연시간 학습데이터, 제주 일별 여객 | SARIMAX, 시계열 회귀 |
| 항공 안전 분석 | NTSB + 국토교통부 사고 건별 기록 | 원인 분류, 빈도 모델 |
| 공항·노선 수요 예측 | 인천 운송실적, 기종별 운송실적 | 패널 회귀, 시계열 군집 |

**주의:** 출발 전 지연을 예측할 때는 `DepDelay`, `ArrDelay`, `CarrierDelay`, 실제 시각처럼 운항 후에 확정되는 값을 입력 변수로 쓰면 안 된다. 검증도 무작위 분할 대신 시간순으로 나눈다.
